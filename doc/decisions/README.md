# 关键决策记录

一个决定一个文件：`NNNN-简短英文名.md`，编号递增，不复用。照 [template.md](template.md) 写。

**什么时候写一份：**

- 有几种可行做法，选了其中一种；
- 以后不容易改，或者改了会影响已有的结果、数据或文件格式；
- 过几个月别人（或你自己）会问"为什么这样做"。

例如：退化接口怎么扩展、输出文件的格式和命名、可复现性规则、第三方代码怎么处理、依赖的选择。
日常的 bug 修复、小重构不用写，看提交记录就够了。

**状态：** 提议（还在讨论）→ 已采纳；以后被推翻时不删除原文件，把状态改成"已被 NNNN 取代"或"已废弃"，再新写一份。
